# Дефекты и продуктовые риски

**Окружение (для обоих дефектов):** эмулятор Pixel 6, Android 14 (API 34), my moldcell 1.44.1 (12554) из Google Play, язык приложения English, сеть Wi-Fi.

## BUG-01
**Сообщение об ошибке формата логина не исчезает после ввода корректного значения**

| | |
|---|---|
| Severity | Minor |
| Priority | Medium |
| Где | Экран входа (`login_input`), экран восстановления пароля (`username_login_input`) |

**Предусловия:** приложение установлено, выбран язык English, открыт экран входа.

**Шаги:**
1. В поле «Moldcell number or email» ввести `6912`.
2. Нажать «Login».
3. Не нажимая «Login», заменить значение на корректный email `qa.test@example.com` (или на 8-значный номер без ведущего 0).

**Фактический результат:** под полем остаётся красная ошибка «Your username must be a phone number (without leading 0) or an email address.», поле подсвечено как ошибочное. При следующем нажатии «Login» запрос всё же уходит на сервер (приходит «Invalid username or password.»), то есть значение на самом деле валидно.

**Ожидаемый результат:** после ввода корректного значения ошибка скрывается сразу (или хотя бы не показывает, что валидное значение неверно).

**Влияние:** пользователь, ошибившийся один раз, видит, что даже правильный номер «не подходит», и может бросить вход или восстановление пароля. Воспроизводится 3/3 на чистой установке.

**Доказательства:** [шаг 1 — ошибка после Login](evidence/bug1_step1_error_after_login.png), [шаг 3 — валидный email](evidence/bug1_step2_valid_email_still_error.png), [валидный номер](evidence/bug1_step3_valid_number_still_error.png).

## BUG-02
**Переключатель видимости пароля недоступен для TalkBack (нет подписи)**

| | |
|---|---|
| Severity | Minor |
| Priority | Medium |
| Где | Экран входа и регистрации, элемент `hide_password_image` |

**Предусловия:** открыт экран входа.

**Шаги:**
1. Снять дамп иерархии (`adb shell uiautomator dump`) или включить TalkBack.
2. Перейти фокусом к иконке «глаз» в поле Password.

**Фактический результат:** элемент кликабельный и фокусируемый, но `text=""`, `content-desc=""`; UiAutomator помечает его `NAF="true"` (Not Accessibility Friendly). TalkBack озвучит его как «Кнопка, без метки» — незрячий пользователь не поймёт назначение.

**Ожидаемый результат:** у переключателя есть `contentDescription`, зависящее от состояния, например «Show password» / «Hide password».

**Доказательства:** [скрин](evidence/bug2_password_toggle_unlabeled.png), [узел из дампа](evidence/bug2_password_toggle_node.xml).

## Product risks
**R-01. Перечисление учётных записей через восстановление пароля.** Экран входа отвечает нейтрально («Invalid username or password.»), а восстановление пароля для несуществующего email отвечает «User not found.» — по ответу можно перебором узнать, какие номера/email зарегистрированы в my moldcell. *Как проверить:* отправить восстановление для заведомо несуществующего и для тестового существующего аккаунта (выданного командой) и сравнить ответы, а также проверить rate limit на эндпоинте (N запросов подряд → блокировка/капча). Согласовать с безопасностью, ожидаемый ответ — одинаковый для обоих случаев.

**Мелкое:** опечатка «Connection error occured while loading.» → «occurred» (Trivial / Low).
