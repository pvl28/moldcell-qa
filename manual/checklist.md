# Чек-лист: my moldcell (часть без авторизации)

Окружение: эмулятор Pixel 6 (1080×2400), Android 14 / API 34 (Google Play image, arm64), приложение **my moldcell 1.44.1 (12554)** из Google Play, язык приложения — English. Дата: 30.10.2026.

Тестовые данные: только заведомо несуществующие значения (`6912`, `qa.test@example.com` — зарезервированный домен). Реальные номера на сервер не отправлялись, регистрация и OTP не запускались.

**Приоритизация.** Приоритет = влияние сбоя на основной путь абонента (запуск → вход или восстановление доступа) × вероятность ситуации у реального пользователя; риск для безопасности повышает приоритет. Основные риски: невозможность войти или восстановить доступ, ошибки валидации логина, поведение без сети, раскрытие данных об учётных записях, недоступность для экранных чтецов.

- **High** — блокирует или искажает вход и восстановление доступа, затрагивает каждого нового пользователя или безопасность.
- **Medium** — второстепенные пути и качество: навигация, регистрация (без отправки), доступность, сеть на вторичных экранах. Сбой неприятен, но вход возможен.
- **Low** — не влияет на вход и данные.
